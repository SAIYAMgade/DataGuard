# DataGuard | Reports Directory

This directory contains executable and generated report artifacts produced by the DataGuard pipeline.

## Deliverables

- `DataGuard_Quality_Report.xlsx`: Comprehensive 6-sheet Excel workbook generated by openpyxl containing the executive summary, exception register, multi-currency reconciliation, quality trends, data dictionary, and rule catalogue.
- `sample_outputs/`: Machine-readable CSV extracts exported for Power BI direct import:
  - `kpis_export.csv`: Current batch summary KPIs.
  - `exceptions_export.csv`: Full exception register snapshot.
  - `reconciliation_export.csv`: Multi-currency reconciliation variances.
  - `quality_runs_export.csv`: Historical quality score run log.
